Reclaim automatically discovers Engines/FFmpeg/ffmpeg.exe inside Reclaim-App for local video repair. Keep this Engines folder inside Reclaim-App. This independently obtained local engine is not included in the GitHub source or ZIP produced by the source build script. Users of that ZIP can obtain their own engine using the download instructions in the application guide. Preserve the original LICENSE and README beside ffmpeg.exe.
